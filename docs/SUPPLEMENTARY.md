# Supplementary material

Run `scripts/plot_figures.jl --figures supplementary` for all outputs, or select
individual IDs below. The time-series IDs select different experimental workbooks.

| ID | Output stem under figures/supplementary | Input |
| --- | --- | --- |
| supp-kop | Fig_KOP_exp_broken_axis | KOP_Exp.xlsx |
| supp-timeseries | Fig_min_r_timeseries | min(r).xlsx |
| supp-timeseries-book2 | Fig_min_r_timeseries_book2 | Book2.xlsx |
| supp-stability | Fig_linear_stability_localization | locked_spectrum.jld2 |
| supp-stability-zoom | Fig_linear_stability_localization_spectrum_xlim_m0p2_0p2 | same spectrum dataset |

Experimental workbooks belong in `data/supplementary/experimental/`; the spectrum
and its summary/recovery CSVs belong in `data/supplementary/numerical/`.
The two stability IDs share a single generation calculation.

## Experimental plots

The KOP plot reads measured order parameters. The time-series plots draw measured
amplitudes and sine curves using the y0, xc, w and A parameters already stored in
the workbooks. No new fit is inferred and experimental measurements are not
generated by the code.

`min(r).xlsx` contains worksheets `I=0.94` and `I=0.89`.
`Book2.xlsx` uses two blocks in Sheet1 for I=0.94 and I=0.85.

## Numerical stability scan

The stability scan uses:

| Setting | Value |
| --- | --- |
| N | 5000 |
| C1, C2 | −0.5, −7 |
| K grid | 1.0 to 0.95, decreasing, 51 points |
| First simulation transient / recording / sampling | 2000 / 1000 / 0.1 |
| Initial analysis window | last 100 time units |
| Frequency distribution | symmetric Gaussian pairs, mean 0, standard deviation 0.3 |
| Frequency seed / initial-state seed | 1234 / 5678 |
| Equilibrium residual tolerance | 1e−8 |
| Continuation method | fixed_K |
| Stay on stable branch / stop at first Hopf | true / false |
| Hopf imaginary / real / stability tolerances | 1e−6 / 1e−6 / 1e−7 |
| Localized participation-ratio threshold | 3 |
| Collective participation-ratio fraction | 0.25 |

The calculation finds rotating equilibria with a phase constraint, continues
them using Newton iteration, and computes the full Jacobian spectrum and
eigenvectors. The neutral phase mode is removed for stability analysis.
Initial simulation tolerances are 1e−9 and Newton tolerances are 1e−10.

The archive has 51 accepted points, 10000 eigenvalues per point, critical index
37 and dominant oscillator 199. Its interpolated Hopf point is approximately
K=0.964627876. This separate equilibrium scan does not replace the K_HB marker
from the main dynamical continuation figure.

Regenerate only this scan with:

```sh
julia --project=. scripts/generate_data.jl --figures supp-stability
```

Plotting the archive performs no simulation or eigendecomposition. Regeneration at
N=5000 requires a dense 10000×10000 Jacobian and a full eigenvector decomposition
at every point, with several GiB of memory needed. See [VALIDATION.md](VALIDATION.md)
for the limits of the completed checks.

For a small pipeline check, add `--smoke --data-dir supp-smoke-data` to the
generation and plotting commands. This uses N=12 and three coupling points,
not the paper's stability spectrum.
