Run `scripts/plot_figures.jl --figures supplementary` for all outputs, or select
individual IDs below. IDs are descriptive because manuscript supplementary
numbering is not recorded in the source tree. Both time-series variants are
included so the final manuscript choice can be made explicitly.

Experimental workbooks belong in `data/supplementary/experimental/`; the spectrum
and its summary/recovery CSVs belong in `data/supplementary/numerical/`.
The two stability IDs share a single generation calculation.

## Experimental plots

The KOP plot reads measured order parameters. The time-series plots draw measured
amplitudes and sine curves using the y0, xc, w and A parameters already stored in
the workbooks. No new fit is inferred and experimental measurements are not
generated by the code.

`min(r).xlsx` contains worksheets `I=0.94` and `I=0.89`. The second worksheet
was previously misnamed; its correct illumination is **I=0.89**, as confirmed
by the author. The publication dataset and figure label both use I=0.89.
`Book2.xlsx` uses two blocks in Sheet1 for I=0.94 and I=0.85.
The older `Fig_min_r_timeseries_final.png` is an additional presentation variant
without a matching source script; this repository reproduces the current script
layouts using the same underlying measurements. The older PNG's I=0.88 label is
also incorrect and is superseded by the corrected I=0.89 output.

## Numerical stability scan

The archived spectrum data directly confirm:

| Setting | Value |
| --- | --- |
| N | 5000 |
| C1, C2 | −0.5, −7 |
| K grid | 1.0 to 0.95, decreasing, 51 points |
| First simulation transient / recording / sampling | 2000 / 1000 / 0.1 |
| Initial analysis window | last 100 time units |
| Frequency distribution | symmetric Gaussian pairs, mean 0, standard deviation 0.3 |
| Frequency seed / initial-state seed | 1234 / 5678 |
| Equilibrium residual tolerance | 1e−8 |
| Continuation method | fixed_K |
| Stay on stable branch / stop at first Hopf | true / false |
| Hopf imaginary / real / stability tolerances | 1e−6 / 1e−6 / 1e−7 |
| Localized participation-ratio threshold | 3 |
| Collective participation-ratio fraction | 0.25 |

Generation preserves the original first-K simulation, phase/FFT diagnostics,
rotating equilibrium with a phase constraint, Newton continuation, branch-recovery
logic, full Jacobian/eigenvectors, neutral phase-mode removal and Hopf interpolation.
Initial simulation tolerances (1e−9), Newton tolerances (1e−10), and other settings
not saved in the archive use the original source defaults. Pseudo-arclength
helpers are retained from the source but are inactive in fixed_K mode.

The archive has 51 accepted points, 10000 eigenvalues per point, critical index
37 and dominant oscillator 199. Its interpolated Hopf point is approximately
K=0.964627876. This separate equilibrium scan does not replace the K_HB marker
from the main dynamical continuation figure.

Regenerate only this scan with:

```sh
julia --project=. scripts/generate_data.jl --figures supp-stability
```

Plotting an archive performs no simulation or eigendecomposition. Generation at
N=5000 uses a dense 10000×10000 Jacobian and a full eigenvector decomposition at
every point. The Jacobian alone occupies about 763 MiB; complex eigenvectors
alone occupy about 1.49 GiB, with additional arrays and solver workspace required.
Full-size stability regeneration was not performed during repository preparation.

The supplementary smoke mode uses N=12, three K points (1.0, 0.99, 0.98), transient
100, recording 30 and analysis window 10. It validates the pipeline and is not a
reproduction of the paper's stability spectrum.
