# PhaSingInc

Julia code and plotting scripts for *Phase Singularities as a Route to Partial
Incoherence in Coupled Oscillators – From Experiment to Theory*. The repository reproduces main Figures
2, 3, 4 and 6, together with supplementary plots, from the accompanying data.
Raw experimental data for Figures 1 and 5 are provided on Zenodo; their plotting
scripts are not included.

Dataset DOI and software DOI: **pending publication**.

## Installation

Use **Julia 1.12.1**, the version used for validation. From this directory:

```sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

`Project.toml` and `Manifest.toml` specify the dependencies and their versions.

## Reproduce the figures

Download the accompanying Zenodo dataset and extract it under `data/` using
the layout in [DATA.md](docs/DATA.md). Then run:

```sh
julia --project=. scripts/plot_figures.jl
```

This reads archived data without running simulations and writes Figures 2–4 and 6
as PDF and PNG to `figures/`. To include supplementary plots, use
`--figures all`; for supplementary plots alone, use `--figures supplementary`.
Supplementary outputs go to `figures/supplementary/`.

Individual figures and custom directories can be selected, for example:

```sh
julia --project=. scripts/plot_figures.jl --figures 2,6 --data-dir /path/to/data --output-dir /path/to/figures
```

Quote paths containing spaces. Commands also work in PowerShell. Supplementary
figure IDs and inputs are listed in [SUPPLEMENTARY.md](docs/SUPPLEMENTARY.md).

## Regenerate numerical data

Place the experimental workbooks in the documented data directories, then run:

```sh
julia --project=. scripts/generate_data.jl
```

The default calculation uses 5,000 oscillators and a decreasing coupling sweep
with 151 points, followed by the Figure 3 trajectories and Figure 4 spectra.
This is a substantial computation; archived data are recommended for plotting.
Parameters and file formats are documented in [DATA.md](docs/DATA.md).

Use `--skip-continuation --figures 3,4` to regenerate only the derived data from
saved states. Use `--figures supp-stability` for the independent supplementary
stability scan, or `--figures all` for all numerical datasets. Experimental
measurements must be downloaded and cannot be regenerated by these simulations.

Generation refuses to replace an existing numerical dataset unless `--force`
is supplied. Use a separate `--data-dir` for comparison runs. Both scripts
support `--help` for all options.

## Checks and citation

```sh
julia --project=. test/runtests.jl
julia --project=. scripts/generate_data.jl --smoke --data-dir smoke-data
julia --project=. scripts/plot_figures.jl --smoke --data-dir smoke-data --output-dir smoke-figures
```

The smoke run checks the pipeline at small size; it does not reproduce the
paper results. See [VALIDATION.md](docs/VALIDATION.md) for completed checks and limits.
