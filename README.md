# AmpDefInc

Julia code to reproduce the numerical data, main Figures 2–5 and supplementary figures of the
FreqClusters paper on amplitude defects in heterogeneous Stuart–Landau oscillators.
The final manuscript title and publication identifiers will be added before release.

Figure 1 is supplied experimental material on Zenodo and has no generation script.
Experimental measurements cannot be regenerated by numerical simulation: download
the workbooks from the accompanying data record. Exploratory studies are outside
this repository.

## Installation

Use **Julia 1.12.1**, the version used to validate this repository. From this folder:

```sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

`Project.toml` lists the required dependencies; `Manifest.toml` pins the complete
environment. These are the only TOML files. No sibling `SLH` or `FreqClusters`
checkout is required. First installation and package compilation need Internet
access and may take several minutes.

## Reproduce the figures from archived data

Dataset DOI: **pending Zenodo publication**. Place the archive contents under
`data/` following [the data layout](docs/DATA.md), then run:

```sh
julia --project=. scripts/plot_figures.jl
```

This writes `figures/Fig_2.pdf` through `Fig_5.pdf` and matching PNGs. Plotting reads
saved CSVs, workbooks, rotating-frame diagnostics and FFT spectra; it does not
integrate the oscillator model. For individual figures or another directory:

```sh
julia --project=. scripts/plot_figures.jl --figures 2,5 --data-dir /path/to/data --output-dir /path/to/figures
```

To include the supplementary material:

```sh
julia --project=. scripts/plot_figures.jl --figures all
julia --project=. scripts/plot_figures.jl --figures supplementary
```

Supplementary PDFs and PNGs go to `figures/supplementary/`. The default selection
remains main Figures 2–5. Named supplementary IDs can be mixed with main figures,
for example `--figures 2,supp-kop,supp-stability-zoom`. See
[SUPPLEMENTARY.md](docs/SUPPLEMENTARY.md) for all IDs and input files.

Quote paths containing spaces. The commands also work in PowerShell.
The default font is Times New Roman when installed in the Windows font directory,
otherwise Makie's bundled TeX Gyre Heros Makie font. Set `AMPDEFINC_FONT` to an
installed font name or font-file path to override it. Font substitution can change
text placement, while keeping the numerical results unchanged.

## Generate the numerical data

Place the experimental workbooks under `data/experimental/`, then run:

```sh
julia --project=. scripts/generate_data.jl
julia --project=. scripts/plot_figures.jl
```

Generation first performs the decreasing-K continuation, then saves the
Figure 3 rotating-frame diagnostics and Figure 4 FFT spectra. The paper settings,
read from all 151 archived restart files, are:

| Setting | Value |
| --- | --- |
| Oscillators | **N = 5000** |
| Coupling sweep | K = 1.0 to 0.85, 151 points, decreasing |
| C1, C2 | −0.5, −7.0 |
| Transient | 3000 at every K, including the first |
| Recording interval / sampling interval | 600 / 0.1 |
| Main relative / absolute tolerance | 1e−8 / 1e−8 |
| Frequency distribution | Gaussian, mean 0, standard deviation 0.3, symmetric pairs |
| Frequency seed / initial-state seed | 1234 / 5678 |
| Continuation noise | 0 |
| Amplitude-cluster threshold | 0.7 |
| Cluster diagnostic relative / absolute tolerance | 1e−4 / 1e−4 |

The next K starts from the preceding final state. Preserve sweep order, oscillator
ordering and seeds; changing them can change the selected branch and highlighted
oscillators. Derived Figure 3/4 simulations use their original separate recording
times and tolerances, documented in [DATA.md](docs/DATA.md).

To retain an existing continuation dataset and generate only the derived data:

```sh
julia --project=. scripts/generate_data.jl --skip-continuation --figures 3,4
```

The supplementary stability dataset is an independent equilibrium/eigenvalue scan.
Generate it without rerunning the main continuation with:

```sh
julia --project=. scripts/generate_data.jl --figures supp-stability
```

Use `--figures all` to generate main and supplementary numerical data together.
Add `--skip-stability` to retain the archived supplementary spectrum. Experimental
supplements read measured workbooks and their stored fit parameters.

Use `--continuation-only` to omit derived data. Generation refuses to replace an
existing numerical directory unless `--force` is supplied; use a new `--data-dir`
for comparisons. Generated `SHA256SUMS` records checksums of data files for archiving.

The default paper continuation is a substantial computation. Prefer the Zenodo
data for plotting; see [VALIDATION.md](docs/VALIDATION.md) for the measured checks
and the limits of validation. A complete independent 151-point rerun must not be
inferred from a successful small test.

## Small pipeline check

```sh
julia --project=. test/runtests.jl
julia --project=. scripts/generate_data.jl --smoke --data-dir smoke-data
julia --project=. scripts/plot_figures.jl --smoke --data-dir smoke-data --output-dir smoke-figures
```

The smoke run uses N=32, three K points, transient 2 and recording time 2. It
produces a diagnostic plot, not paper figures. Experimental workbooks are not
required. Both entrypoints support `--help`.

A supplementary smoke check uses N=12 and three stability points:

```sh
julia --project=. scripts/generate_data.jl --smoke --figures supp-stability --data-dir supp-smoke-data
julia --project=. scripts/plot_figures.jl --smoke --figures supp-stability --data-dir supp-smoke-data --output-dir supp-smoke-figures
```

## Figure definitions

| Figure | Inputs / calculation |
| --- | --- |
| 1 | External experimental data on Zenodo; no script |
| 2 | Continuation mean frequencies and radius extrema; two experimental workbooks |
| 3 | Selected oscillator 199 in a frame rotating at the high-amplitude oscillator frequency; three modulation periods or a fixed-point diagnostic |
| 4 | Saved amplitude and real-component FFTs; experimental FFT workbook |
| 5 | Continuation frequencies, minimum radii and cluster order parameters |

Figure 5 follows the archived `Fig_5` output: its frequency order parameter uses
the **mean-frequency** definition, not the instantaneous-frequency diagnostic
also present in the continuation CSV. Its transition markers retain K_HB=0.963
and K_def=0.948 from the original paper plot.
